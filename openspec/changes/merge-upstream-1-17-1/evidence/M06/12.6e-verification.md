## Boundaries not exercised

The migration DDL was compiled for PostgreSQL/MySQL but not run against live databases. Real Aliyun Logstore behavior, cross-process concurrency, and index visibility were not exercised. Logstore-to-SQL dual-write retains its existing best-effort backup semantics; no cross-store atomicity is claimed. The `from_account_id` event field is read through raw SDK records because upstream-derived Logstore indexes do not include this fork field. The downstream statistics task must separately verify its Logstore query/index contract.
