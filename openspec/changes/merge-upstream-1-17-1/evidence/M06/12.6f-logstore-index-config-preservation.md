## Root cause and correction

The locally installed `aliyun-log-python-sdk` 0.9.44 implements `LogClient.update_index` as a PUT whose body is `json.dumps(index_detail.to_json())`. Rebuilding `IndexConfig` from only line/keys/scan discards existing SDK attributes, resets TTL and modification metadata, and removes serialized all-keys, log-reduce, maximum text length, and reduce-list settings. The old fallback also adds a line index when none existed. Replacing an actor index with the default required key discards its tokenizer, case sensitivity, Chinese segmentation flag, and alias.

The merge now makes a shallow copy of the existing `IndexConfig` and replaces only its copied field dictionary. Existing nested settings are retained by reference and never mutated by reconciliation. An existing actor key is copied before correcting its required type and analytics flag; only `index_type` and `doc_value` change. Missing keys still receive the required defaults. Other fields retain their previous JSON/text compatibility and mismatch behavior.
