# M08 14.2d：Dify-Plus 文档接回与额度契约澄清

## 结果

在保留 upstream README 主体的前提下，恢复了 Dify-Plus 的根目录入口、稳定开发提示、当前执行状态入口和文档边界。没有把规划快照、runbook 或旧发布记录描述成当前已发布/已部署状态。

额度描述按当前接口与模型实现校正：个人账号 `total_quota` / `used_quota` 是 Dify-Plus 独立余额；App API Key 的 `day_limit_quota` / `month_limit_quota` 是周期限制；`accumulated_quota` 记录累计已用量，不是 Key 生命周期总额限制。
