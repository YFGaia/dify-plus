# M08 14.2g：API Key manager 角色测试夹具修正

Luna 首次运行 `api-secret-key-button.spec.tsx` 时 manager 正向和撤权场景未渲染按钮。根因在测试夹具：`web/context/workspace-state.ts` 校验 current workspace query；生成 schema `zCurrentWorkspaceSummaryResponse` 要求 `admin_extend` 与 `tenant_extend`，而 spec 的 `currentWorkspace` override 和撤权重置只提供 `role`。查询校验失败后角色 atom 使用默认 `normal`，与失败 DOM 一致。
