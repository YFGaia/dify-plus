### 配额语义必须如实表述

当前代码支持独立于 Dify Cloud 套餐/配额的 fork 账号额度：`AccountMoneyExtend` 的 `total_quota` / `used_quota` 在 `api/models/account_money_extend.py:6-18`，账户和 API Key 额度检查分别位于 `api/controllers/service_api/wraps.py:461-473`。Console 的额度管理页存在于 `web/app/(commonLayout)/system-manage-extend/quota-management/page.tsx`，系统管理布局对非 workspace owner 显示无权限（`web/app/(commonLayout)/system-manage-extend/layout.tsx:18-31`）。

API Key 有日/月硬限制：`day_limit_quota`、`month_limit_quota` 的校验在 `api/controllers/console/apikey.py:63-73`，运行时比较在 `wraps.py:468-473`。`api_token_money_extend.accumulated_quota` 是累计用量记录（`api/models/api_token_money_extend.py:15-19`），当前代码没有单独的 API Key 累计总额硬上限。`-1` 的无限值只定义在 API Key 日/月限制字段；不要把该语义推广到账户总额。

相应地，`docs/dify-plus/二开功能详解-后端与数据层.md` 把 `api_token_money_extend` 称作“API Key 额度总表”，容易被理解成累计总额限额。若更新该文档，应明确累计字段只作使用统计，实际限额是日/月两项。
