## Cause and repair

- `packages/contracts/generated/api/console/apps/types.gen.ts` declares `webapp_auth_enabled_extend` optional, while the app detail Zod schemas use `z.boolean().optional().default(true)`. Parsed query output therefore requires a boolean. `updateCachedAppMetadata` previously spread the optional source type into its return, producing an optional field at the typed query-cache boundary.
- The cache updater now writes `webapp_auth_enabled_extend: cachedApp.webapp_auth_enabled_extend ?? true`. An explicit cached `false` remains false, and an absent value receives the schema's effective default. `AppMetadata` contains editable metadata only, so its updates do not overwrite the cached authentication setting.
- `CurrentWorkspaceSummaryResponse` in `api/controllers/console/workspace/workspace.py` requires `admin_extend` and `tenant_extend`. Added false defaults to the shared state fixture, current-workspace query fixture, and workspace-card fixture. Shared fixture overrides still follow the defaults, allowing permission-specific tests to override either field.
- Generated contracts were not changed. No index or commit changes were made.
