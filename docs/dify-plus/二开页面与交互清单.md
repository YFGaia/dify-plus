# Dify-Plus 页面与交互清单

本清单描述当前 Dify Web 中可访问的二开入口。系统管理采用 Dify 原生 Web 与 Flask API，不需要 GVA 管理端。完整行为说明见 [Web 与原生管理后台](./二开功能详解-Web与管理后台.md)。

## 页面入口

| 页面/入口 | 路由或位置 | 主要功能 | 权限与条件 |
| --- | --- | --- | --- |
| 应用中心 | `/explore/apps-center-extend` | 分类、标签、关键词筛选；按使用量排列；进入已安装应用 | 当前登录账号可访问的应用 |
| 模板共享 | 工作室应用卡片操作菜单 | 同步到应用模板、取消同步 | 工作区管理权限及二开管理/工作区权限；同步状态已取得 |
| 企业登录 | `/signin` | Casdoor 登录入口，按配置显示按钮名称 | 服务端确认 Casdoor 已启用且入口可用 |
| 企业登录结果 | `/signin/casdoor-result` | 登录结果与必要提示 | 结果来自服务端判定 |
| Web App 访问认证 | 应用访问入口中的 Web App 卡片 | 开启/关闭访问认证 | Web App 已运行且拥有应用编辑权限 |
| Web App 登录 | `/webapp-signin` | 组织/成员组登录或外部成员 SSO | 系统 Web App 认证启用且访问模式匹配 |
| 个人额度 | 主导航余额区 | 已用额度、总额度、余额；人民币换算 | 登录账号、有效金额和汇率；总额度非零 |
| 应用 API Key | 应用访问入口的 API Key 弹窗 | 创建、编辑描述与日/月限额；查看用量；复制、删除 | 当前应用的密钥管理权限 |
| 记忆上下文 | 经典应用配置 | 保留数量开关、滑杆与数字输入 | 应用配置权限 |
| 上下文分界 | 会话消息列表 | 查看清除上下文标记、恢复分界 | 当前 Console 会话及可访问的会话 |
| 系统集成 | `/system-manage-extend/system-integration` | Casdoor、钉钉、OAuth2 配置 | 初始化工作区实际 owner/admin；Casdoor 另检查专项权限 |
| 用户额度管理 | `/system-manage-extend/quota-management` | 成员搜索、额度排行、分页、总额度编辑 | 初始化工作区实际 owner/admin |
| 代码执行控制 | `/system-manage-extend/code-execution-control` | 工作区 owner 邮箱名单新增/删除，完整执行环境授权 | 初始化工作区实际 owner/admin |

`/system-manage-extend` 默认进入系统集成。系统集成默认打开 Casdoor，可用 `?tab=dingtalk` 或 `?tab=oauth2` 指定其他标签页。系统管理权限由后端以初始化工作区和实际数据库角色判定，普通工作区 owner/admin 不自动获得该权限。

## 用户操作与结果

| 操作 | 数据或接口 | 成功结果与约束 |
| --- | --- | --- |
| 搜索应用 | 已安装应用列表、应用标签 | 按分类/标签及名称、说明关键词过滤；同应用去重 |
| 新建对话 | 安装应用路由解析 | 进入对应已安装应用；保持正确的应用路由 |
| 同步模板 | `PUT /console/api/apps/{app_id}/sync` | 确认后发布模板，刷新同步状态 |
| 取消模板同步 | `DELETE /console/api/apps/{app_id}/sync` | 确认后取消同步，刷新同步状态 |
| 企业登录 | `/console/api/auth/casdoor/display` 与后端登录起始地址 | 服务端发起授权，Web 展示结果 |
| 切换 Web App 认证 | `POST /console/api/apps/{app_id}/site` 的 `webapp_auth_enabled_extend` | 仅提交认证字段，刷新详情；默认开启 |
| 修改应用密钥限额 | `/console/api/apps/{resource_id}/api-keys` 的 POST/PUT | 用途描述最多 50 字符；日/月限额 `-1` 不限、`0` 零额度、非负数有效 |
| 恢复上下文分界 | 消息上下文查询与删除接口 | 删除指定会话消息的分界记录，刷新标记；无 Console 会话时不发起受保护请求 |
| 保存 Casdoor | 系统集成 Casdoor 配置接口 | 保存草稿，保留/替换 Secret；并发版本冲突时刷新核对 |
| 配置 SSO 角色映射 | Casdoor 工作区角色映射 | 为 SSO 登录选择目标工作区及 admin/editor/normal 角色；不赋予 owner |
| 测试/启用 Casdoor | Casdoor 静态校验、测试登录与激活接口 | 实际登录测试通过并被服务端确认后才能启用对应版本 |
| 保存/测试钉钉 | `/console/api/system-manage-extend/integration/dingtalk` | 保存凭证与邮箱补全配置，测试连接 |
| 测试邮箱查询 | `/console/api/system-manage-extend/integration/email-api/test` | 使用测试用户 ID，展示提取邮箱或明确错误 |
| 保存/测试 OAuth2 | `/console/api/system-manage-extend/integration/oauth2` 及 `/test` | 保存集成配置，测试连接 |
| 搜索/修改个人额度 | `/console/api/system-manage-extend/quota-management` 及 `/set` | 展示 USD 额度；总额度设为非负值，已用额度保留 |
| 管理代码执行名单 | 系统管理 `code-execution-control` 接口 | 保存邮箱授权，删除需确认；缓存未同步时提示 |

个人 `total_quota` / `used_quota` 表示 Dify-Plus 余额。密钥 `accumulated_quota` 是累计使用记录，不是终身上限。日、月限额表单仅针对应用密钥。

## 截图使用规则

根目录 [README](../../README.md) 提供功能截图。录图时使用真实运行页面，优先演示数据。发布前遮挡企业认证 URL、组织、Client ID、账号、邮箱、密码、Secret、Token、API Key 和不适合公开的业务数据；保留字段标签、交互控件与布局，以便用户理解功能。

不将未挂载的组件、仅后端提供的接口或历史 GVA 页面列为当前页面。Casdoor 说明聚焦 SSO 配置、校验、登录、回调及必要的工作区角色映射。
