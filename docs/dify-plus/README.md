# Dify-Plus 文档索引

Dify-Plus 在 Dify 中提供企业 SSO、应用分发、个人额度与应用密钥限额、WebApp 访问认证、聊天上下文及代码沙箱管理。系统管理使用 Dify 原生 Console/API，不需要 GVA 独立后台。Casdoor 的产品范围为 SSO 集成。

系统管理统一要求当前空间为实例初始化空间、账号真实角色为 `owner` 或 `admin`；其他空间管理员不能修改全局配置。个人额度与 API 密钥日/月限额独立，累计消费不是生命周期限额。跨空间模型同步的遗留结构不代表当前有可用入口。
