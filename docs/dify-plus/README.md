## 阅读顺序建议

1. 先看 [整体架构图](./整体架构图.md)，理解系统边界、服务关系和数据流。
2. 再看 [与上游差异总表](./与上游差异总表.md)，快速定位 fork 扩展面。
3. 如果关注实现细节，进入后端、前端、数据库、部署专项文档。

## 文档范围

- `api/`：Dify 后端二开功能、扩展配置、迁移与任务
- `web/`：Dify Console/Web 二开页面、接口适配与交互增强
- `admin/`：独立管理后台、统计/配额/系统集成/工作流批处理
- `docker/` 与脚本：整合部署、镜像、环境变量、运维脚本
